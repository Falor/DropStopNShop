# How to change the display

[🇩🇪 Deutsche Version](bedienung.md)

## The one thing to know
**Whatever is in the `Display` folder plays on the monitor.**
You'll find the folder on the PC in File Explorer, under the network drive.

After saving, it takes **up to 3 minutes** until the change is on the monitor.

## Change something (e.g. the price list)
1. Open the presentation in **PowerPoint** (or LibreOffice Impress) and edit text, prices or
   pictures.
2. **Save** it into the `Display` folder and overwrite the old file. That's it.

Every slide is its own slide on the monitor. Instead of the PowerPoint file you can also save a
**PDF** (PowerPoint: File → Save As → PDF; Impress: File → Export As → Export as PDF…). Every page
of the PDF is its own slide. If a PowerPoint slide looks different on the monitor (fonts, layout),
save it as a PDF: that always looks exactly the same.

**Tip:** Use a **presentation** program, not a word processor. Slides have the shape of the
screen. A Writer or Word page is an A4/Letter sheet, and its text looks tiny on the monitor (the
space next to it is filled with the colour at the edge of the page, so there are no black bars). Go
big with the text: 40 pt or more.

## Add something new
Just put a file into the folder:
- **PowerPoint** (`.pptx`)
- **PDF** (from LibreOffice, Canva, Word, …)
- **Image** (JPG or PNG, e.g. a phone photo)
- **Video** (MP4)

## Remove something
- **Delete** the file, or
- Move the file into a subfolder, e.g. `Archive`. It isn't shown there, and you can bring it
  back later.

## Order
Files play in the order of their names, so put numbers in front:

```
01_Price list.pdf
02_Offer of the week.pdf
03_Our team.jpg
04_Product video.mp4
```

## Offer with an end date
Put `until` and the date (year-month-day) into the file name:

```
05_Autumn sale until 2026-11-30.pdf
```

From December 1st on, it disappears from the monitor by itself. The file stays in the folder.

## Switching on and off
Just use the power socket. There's no need to shut down. After switching on, the display
appears after about a minute.

## Trade fair or exhibition
1. Create a folder `Display` on a USB stick and put the files into it.
2. Plug the stick into the little computer and switch it on.

The stick takes priority over the network. No network is needed.

## If something is wrong
- **"No content found" on the monitor:** The `Display` folder is empty, or it only contains
  files the display doesn't know (e.g. Word files: save those as PDF).
- **A change doesn't show up:** Wait 3 minutes. If that doesn't help, switch the power off and
  on again.
- **Otherwise:** call ______________ (phone ______________).
